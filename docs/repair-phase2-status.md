## 口径与边界

- 时间使用设备本地时区，测试采用 Asia/Shanghai。部署使用方应保持业务设备时区一致；本轮不引入全公司固定时区配置。
- 期间明细是“安排/截止在期间内”或“实际完成在期间内”的记录并集，一条事项只计一次。拜访数为并集里的拜访事项数；周图计划柱按安排时间、完成柱按完成时间分别计数。
- 完成率 = 期间实际完成待办 / 期间明细中非取消待办。历史记录没有 completedAt 时不猜测完成日期、不算作期间完成；可在全部时间查看原记录。
- 地区使用关联组织当前维护的 region，不根据详细地址推测，也不自动继承父组织地区。同地区多组织仍计一条事项；跨地区（含已知/未知混合）归“多地区”；缺失或不可见组织归“未填写地区”；没有组织（含仅关联人脉、内部待办）归“未关联组织”。
- 覆盖组织和行业按组织 ID 去重，不按组织名称去重；一条关联多个组织的拜访可覆盖多个组织，但事项数仍只加一。
- 团队仅使用服务端授权的当前部门记录；未增加跨部门权限。私有人脉过滤沿用第一阶段。
- 趋势显示最近六个月，仍服从当前期间、成员和地区筛选，因此选择本月时此前月份为 0；查看最近六个月完整趋势可选“全部时间”。
- 仅替换首页固定创建动态，不把第三阶段 I20 的拜访详情时间线标为已修复。
